# Lead-in bank, organised by cognitive task

Source: generalised from NBME Item-Writing Guide, Ch 6 and Appendix B [NBME pp. 44, 51–55, 70–84]. The guide organises its lead-ins by clinical competency. This bank reorganises them by the **cognitive task** the learner performs, so it works in any domain. The templates are written for this skill. `[X]` marks a slot to fill.

## Rules for every lead-in

[NBME pp. 34, 44]
- One complete, closed question ending in "?".
- Answerable from the stem alone (cover-the-options test).
- A superlative that makes one answer best: *most likely*, *most appropriate*, *best*, *greatest*, *first*, *initial*.
- The lead-in decides what **type** each option must be. Every option must belong to that type (the "Options are" column below).
- No EXCEPT, NOT, or LEAST.
- Refer back to the scenario ("this situation", "these findings", "this employee") so the question can't be answered without reading it.

## 1. Explain: cause, mechanism, underlying principle

| Lead-in template | Options are |
|---|---|
| Which of the following is the most likely cause of [this problem]? | causes |
| Which of the following best explains [these findings / this result]? | explanations |
| Which of the following is the most likely underlying mechanism of [this effect]? | mechanisms |
| Which of the following [principles / concepts] best accounts for [this outcome]? | named principles |
| [This intervention] most likely achieved its effect through which of the following? | mechanisms of the intervention |
| Which of the following processes is most likely [impaired / disrupted] in this situation? | processes |

*Note:* when testing foundational principles, make the scenario require the principle. A learner should not be able to answer from surface pattern-matching alone [NBME pp. 51, 70].

## 2. Locate: component, stage, or point of failure

| Lead-in template | Options are |
|---|---|
| A failure in which of the following [components / stages] most likely explains these findings? | components |
| Which of the following [parts of the process] is at greatest risk during [this procedure]? | parts / stages |
| At which of the following points did the process most likely break down? | process steps |

## 3. Gather information: what to ask, observe, or check next

| Lead-in template | Options are |
|---|---|
| Which of the following additional information is most important to obtain at this time? | pieces of information |
| It is most appropriate to ask [this person] specifically about which of the following? | topics / questions |
| Which of the following is the most appropriate focus of the next [inspection / review / examination]? | areas or techniques to examine |
| Which of the following is the most appropriate next step in [evaluating / investigating] this situation? | investigative steps |

*Note:* options should be things **not already given** in the scenario, and not routine information anyone would have collected at the start [NBME p. 71].

## 4. Predict an observation or result

| Lead-in template | Options are |
|---|---|
| Further [inspection / review] is most likely to show which of the following? | observations |
| [This test / report / analysis] is most likely to show which of the following? | results |
| Which of the following sets of results is most likely? | result combinations (consistent format) |
| Which of the following [measures] is most likely to be [increased / decreased]? | measures |

## 5. Interpret data

| Lead-in template | Options are |
|---|---|
| Which of the following is the most likely explanation for these [results / data]? | interpretations |
| Based on these findings, [the situation] is most likely attributable to which of the following? | attributions |
| Which of the following conclusions is most strongly supported by these data? | conclusions |
| Which of the following is the most accurate interpretation of [this chart / this interval / this result]? | interpretations |

## 6. Classify / diagnose the situation

| Lead-in template | Options are |
|---|---|
| Which of the following most likely describes [this situation / problem]? | categories / named problems |
| Which of the following is the most likely [classification / type / category]? | categories |
| Which of the following best explains these findings? | categories, possibly including "Expected / normal finding" |

*Note:* "No problem / normal finding" can legitimately be the key [NBME p. 73].

## 7. Predict outcome, risk, or consequence

| Lead-in template | Options are |
|---|---|
| Without intervention, [this situation] is most likely to result in which of the following? | outcomes |
| Which of the following is the most likely complication of [this situation]? | complications |
| Which of the following factors in the background most increased the risk of [this outcome]? | factors **present in the scenario** |
| For which of the following is [this person / system] at greatest risk? | risks |

## 8. Prevent

| Lead-in template | Options are |
|---|---|
| Which of the following would most likely have prevented [this outcome]? | preventive actions |
| Which of the following is the most appropriate step to prevent [recurrence / harm]? | preventive actions |
| Which of the following [checks / screens] is most appropriate at this time? | checks |

*Note:* test the principle, not memorised schedules or guidelines that frequently change or conflict [NBME p. 53]. For "would have prevented" items, choose options that would **not** normally have been done already, so the item doesn't become a question about negligence [NBME p. 54].

## 9. Choose an action or intervention

| Lead-in template | Options are |
|---|---|
| Which of the following is the most appropriate next step? | actions |
| Which of the following is the most appropriate **initial** action? | actions |
| Which of the following is the **first priority** in [this situation]? | actions |
| Which of the following is the most appropriate [tool / method / technique] for [this task]? | tools / methods |
| Which of the following is the most appropriate recommendation at this time? | recommendations |

*Notes:*
- In most action items, the learner must first work out what the situation is, then choose what to do [NBME p. 53].
- "No action is needed at this time" or "Continue the current approach" is a legitimate option and can be the key. Use it instead of "None of the above" [NBME pp. 19, 72].
- Match the action to the **level of responsibility** the learner will hold (supervised, independent, specialist) [NBME p. 55].

## 10. Monitor and follow up

| Lead-in template | Options are |
|---|---|
| Which of the following is most appropriate to [monitor / review] periodically in this situation? | measures |
| Which of the following findings would most strongly indicate the need to change the current approach? | findings |
| Before changing [the plan], which of the following is the most appropriate step? | steps |

## 11. Communicate

| Lead-in template | Options are |
|---|---|
| Which of the following is the most appropriate response to [this person]? | quoted statements, parallel in length and tone |
| Which of the following is the most appropriate way to [deliver this news / address this concern]? | approaches |
| Which of the following actions is most likely to improve communication within this team? | actions |

*Note:* text-only communication items tend to be easy because tone and body language are missing [NBME p. 61]. Keep quoted options parallel, and don't make the key the warmest or longest option. Consider video (see `media.md`).

## 12. Professional, ethical, and legal judgment

| Lead-in template | Options are |
|---|---|
| Which of the following is the most appropriate action regarding [this colleague's behaviour]? | actions |
| Which of the following is the primary consideration in deciding [X]? | considerations |
| Which of the following is the most accurate statement about [confidentiality / consent / obligations] in this situation? | statements (homogeneous) |
| Which of the following individuals must [authorise / be informed of] this decision? | roles |
| After the error is documented, which of the following is the most appropriate next step? | actions |

## 13. Systems, quality, and safety

| Lead-in template | Options are |
|---|---|
| Which of the following is the most likely cause of this error? | system or human factors |
| Which of the following is most likely to prevent this type of error from recurring? | system changes |
| Which of the following is the most appropriate immediate action after this incident? | actions |
| Which of the following strategies is most likely to achieve [this goal]? | strategies |
| Which of the following best describes the deviation from standard procedure? | descriptions |

## 14. Quantitative reasoning and research methods

| Lead-in template | Options are |
|---|---|
| Which of the following best describes this study design? | designs |
| Which of the following is the greatest threat to the validity of these findings? | threats (bias, confounding, ...) |
| Which of the following is the most likely effect on [estimate] if [parameter] changes to [value]? | directional effects or values |
| Based on these data, which of the following is closest to the [rate / ratio / risk / value]? | **numbers in ascending order, one format** |
| Which of the following conclusions can be drawn from these data? | conclusions |
| Which of the following is the best interpretation of this [confidence interval / p-value / effect size]? | interpretations |

*Note:* for numeric options, follow ID-NUMERIC in `technical-flaws.md`. Use "closest to" when rounding could otherwise produce more than one correct answer.
