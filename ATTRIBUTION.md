# Attribution and source

## Primary source

The item-writing principles in this skill are drawn from:

> Billings MS, DeRuchie K, Go S, Hussie K, Kulesher A, Merrell J, Morales A, Paniagua MA, Sherlock J, Swygert KA, Tyson J. *Constructing Written Test Questions for the Health Sciences* (NBME Item-Writing Guide). 6th ed. Philadelphia, PA: National Board of Medical Examiners; 2020 (revised October 2024).

The guide is available free from NBME: <https://www.nbme.org/educators/item-writing-guide>. If you write or review test items regularly, read the original. It is short and full of worked examples.

## How this repository uses the source

- **No part of the guide is reproduced here.** The PDF is not committed (see `.gitignore`), and no sample items, tables or extended passages are copied from it.
- The files in `skills/mcq-item-writer/references/` restate the guide's principles **in our own words**, generalised beyond the health sciences, with page citations of the form `[NBME p. 17]` so readers can check the original.
- **All example items in this repository are original.** None are NBME items.
- Material that goes beyond the guide (for example, guidance taken from Haladyna, Downing & Rodriguez, 2002) is labelled as such.
- Lead-in templates use standard phrasing that is conventional across the assessment field (for example, "Which of the following is the most appropriate next step?"). Some therefore match wording in the guide.
- `docs/source-map.md` maps each section of the guide to the file that covers it.
